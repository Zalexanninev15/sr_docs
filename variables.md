# Пользовательские переменные

{% hint style="success" %}
**Пользовательские переменные**, которые могут принимать любые строковые значения для использования в сочетании с командами для более быстрого доступа к необходимому функционалу или упрощению ввода аргументов к командам бота. Посмотреть список всех **пользовательских переменных** можно с помощью кнопки **😎 Плагины и переменные** в меню бота или в настройках приложения.
{% endhint %}

Использование переменой в Telegram боте: `/run *S32*`&#x20;

После ввода команды, откроется папка **System32** в Проводнике Windows (смотрите [пример настройки пользовательских переменных](faq/v5/variables.md))

## Переменные-команды

Чтобы облегчить ввод длинных и часто используемых команд (и аргументов к ним) можно также воспользоваться **пользовательскими переменными**.

В качестве примера использования можно привести запуск команды CMD для команды /pwsh: `/pwsh cmd /c echo %username%`

Данная команда и параметры для неё сокращены до пользовательской переменной **user**, которую можно использовать введя в боте `*user`

Итого: `*user` эквивалентно `/pwsh cmd /c echo %username%`

{% hint style="success" %}
Переменные-команды можно также сочетать с обычными переменными.&#x20;

Вот пример: Имеется переменная-команда `msg`

Данная команда имеет значение `/msg 3 *info*` _(_&#x432;ызов окна с сообщение&#x43C;_)_

Переменная `info` может иметь любой текст. Как результат, при выполнении в Telegram боте `*msg` происходит выполнение команды `/msg` со значением текста в виде значения у переменной`info`
{% endhint %}

{% hint style="info" %}
Вызвать переменные-команды также можно используя `/em_[переменная]` или `1[переменная]` или `/1[переменная]`
{% endhint %}
