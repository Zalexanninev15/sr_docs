# Первый запуск

Скачать последнюю версию можно на [официальном сайте](https://sharkremote.neocities.org/get) и распаковать папку "Shark Remote".

{% hint style="success" %}
При желании можно с лёгкостью установить Shark Remote используя PowerShell (запущенный с правами Администратора) с помощью команды: \
`irm https://sharkremote.neocities.org/deploy | iex`

{% hint style="danger" %}
**⚠️ Данный способ не рекомендуется, если вы планируете хоть как-то взаимодействовать с настройками через WebView2 (WebUI), который запускается по умолчанию при первом запуске Shark Remote.**

![](<../.gitbook/assets/image (47).png>)

![](<../.gitbook/assets/image (46).png>)
{% endhint %}

{% hint style="info" %}
Русский язык во время работы установщика доступен только при запуске из-под PowerShell 7. Стандартный (встроенный в систему) Windows PowerShell будет отображать процесс установки на английском языке.
