# Первый запуск

Скачать последнюю версию можно на [официальном сайте](https://sharkremote.neocities.org/get) и распаковать папку "Shark Remote".&#x20;

{% hint style="success" %}
При желании можно с лёгкостью установить Shark Remote используя PowerShell (запущенный с правами Администратора) с помощью команды: \
`irm https://sharkremote.neocities.org/deploy | iex`

{% hint style="info" %}
Русский язык во время работы установщика доступен только при запуске из-под PowerShell 7. Стандартный встроенный в систему Windows PowerShell будет отображать процесс установки на английском языке.
{% endhint %}
