# Запуск Telegram бота

## Запуск Telegram бота

Обычно, Telegram бот запускается автоматически при запуске приложения.&#x20;

Если этого не произошло, выключите и включите (возможно нужно просто включить) Telegram бота с помощью переключателя/кнопки. Данные компоненты окна используются для активации и деактивации Telegram бота. Судить о работе Telegram бота можно по текстовым полям "Имя", "Username", "Бот ID", а также по статусу ("Статус").

{% hint style="info" %}
Переключение работы Telegram бота может быть произведено через сочетание клавиш Ctrl+S.
{% endhint %}
