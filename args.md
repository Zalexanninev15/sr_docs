# Аргументы запуска приложения

Для файла **Shark Remote.exe** существуют аргументы запуска для активации каких-либо функций.

Пример запуска с аргументом: `Shark Remote.exe --no-window`

{% hint style="info" %}
**Shark Remote** поддерживает более 1 аргумента на вход, но учтите, что некоторые аргументы могут конфликтовать друг с другом и это может сказаться на работоспособности.
{% endhint %}

## Доступные аргументы запуска

* `--help`  (альтернативы: `-h`, `/h`, `?`, `/h`) - открытие документации в браузере
* `--webui2`  (сокращённо: `-set`) - открыть WebUI настроек в браузере
* `--run-confwiz`  (для 7 версии: `--reset`) - принудительно запустить Мастер настройки
* `--autostart`  (сокращённо: `-a`) - управление автозагрузкой и службой Shark Remote. При вводе появится справка по необходимым дополнительным аргументам
* `--install` (сокращённо: `-p`) - открыть диалог для выбора архива с плагином (установка плагина)
* `--init-size` - генерация файла **form\_size.txt** ([подробнее](faq/fix-window.md))
* `--no-window` (сокращённо: `-m`) - запуск в свёрнутом виде (только иконка в трее отображается)
* `--stop` - не запускать Telegram бота автоматически (потребуется нажатие на переключатель)
* `--daemon` (сокращённо: `-i`) - запуск в режиме демона (Служба Windows) (вручную использовать данный аргумент не рекомендуется)
* **⚠️ Удалён в версии 7.0:** `--fix-network-ipv` (сокращённо: `-ipv`) - сброс настроек стека TCP/IP **\[Windows]**. Смотрите [данную страницу](faq/fix_network.md) для проведения аналогичной работы в CMD.
* **⚠️ Удалён в версии 7.0:** `--fix-network-winsock` (сокращённо: `-winsock`) - сброс настроек WinSock **\[Windows]**. Смотрите [данную страницу](faq/fix_network.md) для проведения аналогичной работы в CMD.
* **⚠️ Удалён в версии 7.0:** `--fix-network-dns` (сокращённо: `-dns`) - очистка кэш сопоставителя DNS **\[Windows]**. Смотрите [данную страницу](faq/fix_network.md) для проведения аналогичной работы в CMD.
* **⚠️ Удалён в версии 7.0:** `--fix-download-speed` (сокращённо: `-speed`) - применение "Функции автоматической настройки окон для HTTP-трафика", которая должна улучшить скорость сети **\[Windows]**. Смотрите [данную страницу](faq/fix_network.md) для проведения аналогичной работы в CMD.
* **⚠️ Удалён в версии 7.0:** `--fix-network-ipcfg` (сокращённо: `-ipcfg`) - сброс других сетевых настроек **\[Windows]**. Смотрите [данную страницу](faq/fix_network.md) для проведения аналогичной работы в CMD.
* **⚠️ Удалён в версии 6.2.2:** `--skip-confwiz` (сокращённо `-w`) - выполнить принудительно предварительную настройку бота без запуска Мастера настройки. Запуск: `Shark Remote.exe --skip-sw [токен бота] [username пользователя]`
