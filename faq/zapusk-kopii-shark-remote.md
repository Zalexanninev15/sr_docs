# Запуск копий Shark Remote

Если пользователь захочет запустить сразу два или более Shark Remote, то он столкнётся с проблемой, т.к. может быть запущен только один Shark Remote. Чтобы добавить поддержку нескольких копий: создайте файл `run2` в папках каждой копии (если они в разных папках) или в одной папке.
