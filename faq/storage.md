# Расположение пользовательских файлов и настроек

Все настройки и файлы хранятся исключительно в папке (не должна существовать), путь к которой написан в файле **storage.txt**. Данный файл создаётся при первом запуске Shark Remote и по умолчанию в нём написан путь к папке data в папке с Shark Remote.&#x20;

Путь в файле **storage.txt** можно изменить на любой другой (лучше всего создать файл **storage.txt** вручную, перед первым запуском Shark Remote), главное чтобы папка к которой указан путь не была создана изначально!

{% hint style="info" %}
Устанавливая Shark Remote через PowerShell путь для хранения **ВСЕХ ПОЛЬЗОВАТЕЛЬСКИХ ФАЙЛОВ** будет задан автоматически как **C:\Users\\%username%\AppData\Roaming\Shark Remote** (лёгкий способ попасть в данную папку по пути: **%AppData%\Shark Remote**).
{% endhint %}
