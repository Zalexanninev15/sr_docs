# Я использую скрипты, как мне узнать какая версия на данный момент актуальная?

Всё очень просто!

JSON файл расположен на сайте, необходимо просто сделать запрос/перейти по ссылке [https://sharkremote.neocities.org/assets/update.json](https://sharkremote.neocities.org/assets/update.json)

{% hint style="info" %}
#### Значения:

* `update` - актуальная версия
* `minimal` - минимальная поддерживаемая версия для обновления до последней релизной версии
* `url` - ссылка на апдейтер с последней версией (запуск строго ["тихой" распаковкой](silent-sfx.md))
{% endhint %}
