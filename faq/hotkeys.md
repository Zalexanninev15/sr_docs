# Горячие клавиши приложения и другие действия, интересные "трюки"

{% hint style="info" %}
**Сtrl + S** - включить или выключить Telegram бота

**Ctrl + M** - переключение режимов главного окна приложения (не сохраняется в настройках). Всего существует 2 режима: основной и мини-режим.
{% endhint %}

{% hint style="info" %}
Нажатие на пункт меню Настройки может приводить к разным результатам:

* Обычный клик мышью - открытие [WebUI](https://sharkremote.neocities.org/webuix)
* Клик мышью с зажатым Ctrl - войти в [Автозагрузку](../startup.md)
* Клик мышью с зажатым Alt - скопировать путь в [папку с данными](storage.md), либо открыть её в Проводнике
{% endhint %}

{% hint style="info" %}
Открытие панели _О приложении_ доступно при наведении мышью на надпись _О приложении_ (при первом использовании, "режим новичка") или _Shark Remote_. Если используется Мини-режим – требуется клик (защита от случайного использования).
{% endhint %}
