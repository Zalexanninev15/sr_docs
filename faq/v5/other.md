# Другие настройки

<figure><img src="../../.gitbook/assets/image (43).png" alt=""><figcaption><p>Другие настройки Shark Remote</p></figcaption></figure>

Ниже перечислены описания настроек и их особенности:

* Пропустить проверку токена Telegram бота: управление состоянием проверки токена (рекомендуется включить галочку, если имеются проблемы с подключением к Telegram или боту)
* Пропустить показ плашки загрузки (Splash Screen) - скрытие Splash Screen во время загрузки Shark Remote.
* Отключить проверку обновлений: отключение проверки обновлений (даже в ручном режиме!)
* Служба: использование Shark Remote в виде Службы в Windows, что позволяет запускать Telegram бота при запуске системы, Shark Remote в это время работает в полностью скрытом режиме.

{% hint style="info" %}
Для работы в качестве Службы имеется 2 варианта работы: Службы для всей системы (требуется для работы, например, без входа в пользователя) и обычный вариант.&#x20;

После выбора варианта работы Службы откроется окно Служб, которые установлены в Windows. Найдите Службу "Shark Remote" из списка служб и запустите её.
{% endhint %}
