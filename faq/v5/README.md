## Выбор типа настроек (разделы)

При открытии настроек будет показано общее меню типов настроек.&#x20;

Всего их 4:

* Telegram бота – настройки Telegram бота
* Внешний вид (приложение) – логично, внешний вид приложения (UI)
* Переменные (для Telegram бота) – управление переменными, которые можно использовать в Telegram боте
* Другие настройки – другие настройки приложения и использование Shark Remote  в виде Службы

<figure><img src="../../.gitbook/assets/image (21).png" alt="" width="563"><figcaption><p>Выбор типа настроек</p></figcaption></figure>

{% hint style="info" %}
Перед выходом из настроек необходимо сохранить все внесённые изменения с помощью значка дискеты.&#x20;

Через кнопку "Открыть" можно перейти непосредственно к файлам настроек Shark Remote (папка с их расположением) для редактирования вручную.
{% endhint %}

<figure><img src="../../.gitbook/assets/image (22).png" alt="" width="563"><figcaption><p>Выбор типа настроек (сохранение)</p></figcaption></figure>

## Странный значок

Во время использования вам может попасться странный значок Ø

Данный значок отображает, что настройка или пункт меню недоступен в данный момент и требуется выполнить определённые действия для активации.
