# Внешний вид

{% hint style="info" %}
Внешний вид приложения в дальнейшем (и ранее) будет обозначен как UI (User Interface).
{% endhint %}

<figure><img src="../../.gitbook/assets/image (2).png" alt=""><figcaption><p>Пример настроек внешнего вида (UI)</p></figcaption></figure>

Ниже перечислены описания настроек внешнего вида и их особенности:

* Скругление окон: использование новомодного скругления окон (работает независимо от Windows).
* Мини-режим: активация/деактивация отображения окна в виде его мини-версии с минимальным функционалом (настройка создана для любителей минимализма). Открытие панели "О приложении"/"Shark Remote" происходит нажатием на текст левой кнопкой мыши, а не наведением курсора мыши, как это сделано при использовании обычного окна.\
  Возврат в обычное окно – через открытие панели "О приложении"/"Shark Remote", вторая иконка с правой стороны.

{% hint style="info" %}
Мини-режим и возврат в обычный может происходить и без использования настройки. Для этого используйте сочетание клавиш Ctrl+M. Переключение режимов окна в данном варианте не сохраняется в настройках!
{% endhint %}

* Прозрачность окна: управление прозрачностью окна
* Анимация плавного появления окон: управление анимацией плавного появления окон
* Режим производительности: специальный авторский алгоритм определения и оптимизации окна Shark Remote, чтобы достичь максимальной производительности/избавиться от "лагов".

{% hint style="success" %}
Данный режим может включаться и автоматически при запуске Shark Remote (требуется согласие пользователя) на интегрированных видеокартах от Intel, старых видеокартах от NVIDIA и AMD, а также при запуске ПО в виртуальных машинах, что позволяет улучшить общую отзывчивость UI.
{% endhint %}

{% hint style="danger" %}
Рекомендуется включать вручную, только если имеются реальные проблемы с отзывчивостью UI.
{% endhint %}

* Автоматический размер окон: исправление отображения основного окна на экранах с разрешением 1920x1080 и выше
* Цвет полоски выбора в меню: управление цветом полоски выбора в меню, _Новогодний цвет_ имеет расширенные визуальные решения

{% hint style="warning" %}
Некоторые настройки возможно активировать только при отключении других!&#x20;

Так как настройки некоторых компонентов могут конфликтовать с другими настройками, то было решено блокировать конфликтующие настройки при активации "проблемных".

Несмотря на это, настройки можно редактировать через файл настроек.&#x20;
{% endhint %}
