# Telegram бот

<figure><img src="../../.gitbook/assets/image (41).png" alt=""><figcaption><p>Все настройки Telegram бота</p></figcaption></figure>

Ниже перечислены описания настроек Telegram бота и их особенности:

1. Вставка токена Telegram бота (аналогично настройке в [Мастере настройки](../../hello/settings-wizard.md)). Получить токен Telegram бота можно через [официального бота](https://t.me/BotFather).
2. Изменение администратора (пользователя) для бота (аналогично настройке в [Мастере настройки](../../hello/settings-wizard.md)).
3. Настройка Меню. \
   **Меню** доступно в Telegram боте. Можно использовать команды Telegram бота Shark Remote.

<figure><img src="../../.gitbook/assets/image (24).png" alt=""><figcaption><p>Вызов Меню</p></figcaption></figure>

{% hint style="info" %}
После изменения Меню необходимо использовать команду `/menu` для применения обновлённого Меню.\
\
Готово! Меню будет отображаться в боте следующим образом (скриншот ниже), а при нажатии будет срабатывать команда `/start`
{% endhint %}

<figure><img src="../../.gitbook/assets/image (39).png" alt=""><figcaption><p>Пример Меню</p></figcaption></figure>

4. Настройка включения выполнения отложенных команд. \
   Как пример: Пока Telegram бот выключен, пользователь может отправлять в него команды. Если настройка включена, то все команды, которые были отправлены, пока бот был выключен, будут выполнены при его включении. Настройка отключена по умолчанию!

{% hint style="danger" %}
Внимание! Настройка может привести к проблемам, если отложенных команд окажется очень много. Также возможны баги и нестабильная работа Telegram бота.
{% endhint %}

5. Включение оповещения (уведомления) о статусе Shark Remote на компьютере.\
   Как пример: При включении Telegram бота или при закрытии Shark Remote/выключении Telegram бота будет отправлено сообщение в Telegram.

<figure><img src="../../.gitbook/assets/image (28).png" alt="" width="372"><figcaption><p>Пример работы в старых версиях Shark Remote</p></figcaption></figure>

6. Вставка API ключа для публикации скриншотов командами `/screen w` и `/screen u` на сервисе [ImgBB](https://imgbb.com/)
7. Выбор шрифта и его размера для печати текстовых файлов.
8. Выбор сервиса для определения геолокации (местоположение) компьютера с использованием его публичного IP-адреса. Для сервиса [ipgeolocation](https://ipgeolocation.io/) требуется ввод API ключа.
9. (кнопка должна распологаться сверху слева на скриншоте) Контроль доступа. Настройки контроля доступа позволяют добавить второго пользователя для Telegram бота и (при желании администратора бота) настроить определённые ограничения.&#x20;
