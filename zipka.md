# Подпись ZIP

<figure><img src=".gitbook/assets/image (1).png" alt=""><figcaption><p>Пример использования</p></figcaption></figure>

Для ZIP-архивов имеется возможность разархивирования в папку **saved** или указанную пользователем.

{% hint style="info" %}
Причём, можно добавить **?** и тогда внутри указанной папки будет создана папка с названием архива!
{% endhint %}
