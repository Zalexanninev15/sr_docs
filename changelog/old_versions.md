# Список изменений \[Legacy]

### Версия 7.0 (Re-Release) (24 августа)

Tip

Версия 7.0 имела некоторые проблемы, поэтому была перевыпущена с исправлениями и улучшениями.

* \[Общеее] Возвращён прошлый способ подготовки релизов,.NET 9 вновь не нужен. Убраны лишние файлы.
* \[WebView2] Исправлена ошибка в WebView2, если Shark Remote расположен в _Program Files_.
* \[Telegram бот] Значительно улучшены команды `/cp`, `/del`, `/mv`, `/rk`
* \[Telegram бот] Добавлена команда `/rc`, которая является более совершенной версией команды `/run`
* \[Telegram бот] Терминал KojiOS обновлён до стабильной версии 2.0
* \[Telegram бот] Добавлена поддержка звёздочки **\*** для команд `/run`, `/rc`, `/shell`, `/bash` для этого её нужно записать как `(*)`. Пример: `/runc msg arg:(*) "Hello World!"`
* \[Telegram бот] Улучшены подписи к файлам: **run**, **zip**. Улучшено обычное скачивание файла из Telegram.
* \[Telegram бот] Мелкие улучшения.

### Версия 7.0 (18 августа)

**🥳 Новое и значительные улучшения команд с добавлением нового функционала:**

* \[Telegram бот] Полностью переписана команда **/wc**. Прогресс теперь отображается в боте, добавлена поддержка загрузки сразу нескольких ссылок, исправлены проблемы загрузки. Имеется реализация параллельной загрузки двух файлов.\
  Пример команды для скачивания файлов по 5 ссылкам (это одна команда):\
  `/wc https://github.com/Kong/insomnia/releases/download/core%4011.1.0/inso-provenance.intoto.jsonl https://github.com/Kong/insomnia/releases/download/core%4011.1.0/inso-macos-11.1.0.zip https://go.microsoft.com/fwlink/p/?LinkId=2124703 https://cloud.disroot.org/s/QZoxpMftw6QmCFo/download https://cloud.disroot.org/s/eG85rnB2y5yL6FS/download`
* \[Telegram бот] Переработана команда **/dns**. Теперь можно корректно задать первичный и вторичный DNS-сервер (IPv4) или использовать DHCP. Добавлена обработка ошибок, улучшена производительность, исправлены баги.
* \[Telegram бот] Переписана реализация команд **/file** и **/dir**. Улучшена производительность, добавлены обработчики ошибок, добавлен вывод прогресса, улучшена совместимость с нестандартными папками и файлами, добавлен подсчёт элементов для **/dir**, улучшено определение размеров
* \[Telegram бот] Добавлен новый тестер скорости для команды **/speed**. Задержка теперь определяется в некоторых случаях более корректно, а также будет показан сервер, который использовался для тестирования. Также было замечено значительное ускорение времени работы и более корректное отображение реальных скоростей.
* \[Telegram бот] Полностью переработана команда **/move**. Добавлена справка, улучшено определение координат, добавлен скриншот размером 100x100 пикселей вокруг курсора. Курсор превращён в красный крест, чтобы было удобнее понимать где именно расположен курсор на экране. Добавлена информации по текущим координатам и по возможному диапазону.
* \[Telegram бот] Добавлена команда **/rt** для расширенного взаимодействия с процессом.
* \[Telegram бот] Для команды **/info** значительно улучшен **StorageInfoAPI**. Изменения: повышена скорость сбора информации, добавлена поддержка NVME накопителей, добавлена поддержка RAID, улучшено определение SATA подключений, улучшено определение типа накопителя (SSD/HDD/Flash). Определение типа и интерфейса подключения улучшено также для **Физические диски (сканер 2)**
* \[Telegram бот] При бэкапе/отправке папок (через файловый менеджер Vial или командой **/bak**) файлы, которые имеют большой размер, теперь не будут пропущены при попытке отправки. Добавлен прогресс-бар при отправке файлов и папок.
* \[Telegram бот] Улучшена работа с WSL, ускорена работа, исправлены проблемы с кодировкой при выводе. В настройки Shark Remote добавлена настройка для явного задания дистрибутива для запуска, по умолчанию используется дистрибутив используемый пользователем по умолчанию в WSL. Исправлены баги.
* \[Telegram бот] Переработана команда **/ping**. Добавлена обработка нескольких адресов `/ping youtube.com neocities.org`, добавлен прогресс-бар выполнения пропинговки, улучшена скорость работы и обработка ошибок.
* \[Telegram бот] Для получения информации о батареи `/power g` добавлен новый сканер, который основывается на современном API Windows 10/11. Для удобства, оставлен устаревший метод получения информации об аккумуляторе.
* \[Telegram бот] Переписана почти вся логика работы команды **/sc**. Добавлена работа с несколькими службами (для локального компьютера), значительно ускорен сбор информации об службах. Пример от разработчика: `/sc r WSLService sbiesvc`
* \[Telegram бот] Создание скриншотов теперь доступно и при работе в режиме службы.
* \[Telegram бот] Добавлена поддержка нескольких мониторов для **/snap** и **/screen** при отправке скриншота в Telegram. Для смены методов создания скриншота доступна специальная переменная **sp**, подробнее можно прочитать в [документации](https://zalexanninev15.gitbook.io/shark-remote/hack_av).
* \[Telegram бот] Добавлена команда **/koji** (авторский мини-проект "KojiOS")
* \[Приложение] Для корректной работы интерфейса решено изменять масштаб на 100% принудительно при запуске Shark Remote в режиме первоначальной настройки через Мастер настройки или при показе основного интерфейса в обычном режиме (файл `df100.exe`). Данное поведение можно отключить через настройки.
* \[Приложение] Если Shark Remote установлен в _**Program Files**_, то возможен вариант запуска через алиас `shark` в окне _Выполнить_ (Win+R) или командной строке (CMD) для более быстрого доступа в Shark Remote. Реализовано определение статуса "установлено", что позволяет программе лучше подстраиваться под пользователя.
* \[Приложение] Новые аргументы запуска:\
  `--install` (сокр.: `-p`) для установки плагинов через диалог выбора\
  `--run-confwiz` изменён на `--reset`\
  `--autostart [0-2]` (сокр: `-a`) для настройки автозагрузки. `0` - выключить, `1` - автозагрузка, `2` - служба
* \[Плагины] Поддержка плагинов с применением Python. Поддержка скрипта первоначальной настройки _**setup.py**_ и _**requirements.txt**_. Создание виртуального окружения, когда это необходимо.
