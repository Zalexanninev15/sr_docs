# Список изменений

### Версия 10 CE (Shark Remote XCE)

Релиз Shark Remote 10 с небольшими улучшениями с открытым исходным кодом на Codeberg. Подробности появятся после релиза Shark Remote X.

### Версия 10 (Shark Remote X) (релиз в августе)

* \[Общее] Другие улучшения перед релизом.
* \[Telegram бот] Изменён способ получения текста из буфера обмена командой **/get**.
* \[Telegram бот] Для команды **/dir** добавлен альтернативный вызов через **/folder**.
* \[Приложение] **Данное изменение будет раскрыто после релиза!**
* \[Приложение] Заметно улучшен механизм применения настроек при использовании WebUI Конфигуратора из WebView2.
* \[Telegram бот] Доработан файловый менеджер Vial, который теперь автоматически исключает из списка файлы и папки, к которым у пользователя нет доступа, если они являются системными. Ранее данные элементы были показаны, но доступа к ним всё равно не имелось, поэтому выводилась ошибка.
* \[Общее] Обновлены зависимости до последних версий (как обычно, кроме PowerShell, чтобы обеспечить максимальную совместимость)
* Изменения из бета-версий (смотрите ниже) и [первой бета-версии](old_versions.md#versiya-7.0.1-beta-1-10-beta-1-14-dekabrya).
* \[Общее] Внутренняя версия изменена на формат: "ветка.версия.дата сборки"
* \[Общее] Исправлены "проблемные" участки кода.

### Версия 10 beta 4 (12 июня)

* \[Telegram бот] Добавлена команда **/tip** для показа данных для системных администраторов, их знакомых, коллег и родственников. Команда не отображается в общем списке команд. Вывод команды может обновляться со временем, чтобы быть более актуальным.
* \[Общее] Поддержка HTTP и HTTPS прокси, а также их варианты с данными для входа, что особенно полезно для системных администраторов в организациях, где обычно и используется данный вид прокси для доступа в Интернет. Для настройки прокси необходимо запустить Shark Remote с аргументом `--proxy`\
  `Shark Remote.exe --proxy`.
* \[Приложение] Мелкие визуальные улучшения.
* \[Telegram бот] Отправка 🍕 разработчику заменена на отправку 🧁/ лазаньи.
* \[Telegram бот] Исправлено отображение сообщения для очень редкой ошибки.
* \[Telegram бот] Для команды **/geo** добавлены альтернативные карты. Теперь полный список карт: Google Maps, OpenSteetMaps, Яндекс Карты.
* \[Telegram бот] Для команды **/net** добавлен альтернативный сайт для более подробного просмотра информации об IP адресе. Теперь полный список сайтов для просмотра IP в браузере: BrowserLeaks и 2ip. Для команды **/net** добавлена сокращённая версия - **/ip**.
* \[Общее] Библиотеки обновлены до последних версий.
* \[Telegram бот] Улучшена поддержка способов предоставления информации в кнопках под сообщениями в современном Telegram.
  1. Поддержка до трёх типов состояния кнопок по цветам, возможность копирования текста с помощью кнопки в буфер обмена.
  2. В **/pc** и **Мониторинг** кнопки для запуска бота с командой заменены на более универсальные кнопки для копирования, которые работают на всех платформах, а не только в Telegram Desktop.
  3. В **Меню Избранного** кнопки для запуска бота с командой оставлены в качестве одного из типов запуска.
  4. Поддержка кнопки для копирования для **Меню Избранного**.
* \[Telegram бот] Обновлена устаревшая справочная информация. Исправлены ошибки несоответствия справочной информации с реальной реализацией команд.
* \[Telegram бот] Мелкие улучшения.
* \[Приложение] Двойной клик по значку в трее переключает показ окна приложения.
* \[Приложение] Иконки в приложении заменены на адаптивные с высоким качеством (цветовая палитра не финального варианта).
* \[Telegram бот] Команда **/info** обзавелась аргументами, чтобы быстро выводить только необходимую информацию.

### Версия 10 beta 3 (1 мая)

{% hint style="info" %}
Релиз подготовлен при поддержке хостинга HIP-HOSTING.
{% endhint %}

* \[Telegram бот] Команда **/usage** переименована в **/free**.
* \[Telegram бот] Мелкие улучшения.
* \[WebView2] Обновлена ссылка на установщик WebView2.
* \[Telegram бот] Исправлен подсчёт количества RAM.
* \[Приложение] WebUI2 конфигуратор обновлён до WebUIX для поддержки последней версии.
* \[Telegram бот] Функция работы с shell-кодом из Telegram бота отключена для предотвращения неправомерного использования и поддержания безопасной работы. Включение возможно путём создания параметра **knock-knock=1**
* \[Telegram бот] Команда **/wsl** получила функцию использования дистрибутива на выбор прямо из Telegram бота. Добавлена команда **/wsld** для просмотра информации об установленных дистрибутивах.
* \[Telegram бот] Команда **/speedtest** (сокр.: **/speed**, **/st**) поддерживает использование сторонних ресурсов для тестирования скорости Интернета и задержки. Настройки задаются через файл настроек или WebUI конфигуратор.
* \[Telegram бот] Команда **/history** для вывода истории команд.
* \[Telegram бот] Команда **/gv** для вывода значений переменной.
* \[Telegram бот] Команда **/du** для вывода размера папки и самых больших элементов в ней.
* \[Telegram бот] Команда **/chmod** для задания атрибутов для файлов и папок.
* \[Telegram бот] Команда **/chown** для задания владельцев для файлов и папок.
* \[Telegram бот] Команда **/head** для показа первых N строк текстового файла.
* \[Telegram бот] Команда **/tail** для показа последних N строк текстового файла.
* \[Telegram бот] Команда **/uniq** удалит дубликаты строк в файле (оригинальные строки останутся). **/uniq0** - удалит дубликаты, а также оригинальные строки. **/dub** - показать дубликаты строк (только один раз).
* \[Приложение] Переработана стандартная тема оформления. Задействована официальная функция применения тёмной темы оформления внедрённая в .NET 10. Изменён режим рендера контекстного меню для иконки в трее.
* \[Приложение] Настроить Shark Remote стало возможным напрямую через контекстное меню, которое открывается при клике по иконке в трее.
* \[Приложение] Добавлен просмотр и управление статусом бота через контекстного меню для иконки в трее.
* \[Telegram бот] Команда **/code** выведет содержимое файла в сообщении в оформлении кода (в зависимости от расширения файла).
* \[Telegram бот] Команда **/find** будет осуществлять поиск текста по файлу. **/findx** - поиск с использованием регулярных выражений. В выводе будет отображено число совпадений и найденные строки.
* \[Telegram бот] Команды **/rp** или **/rpx** - выполняют похожие действия, однако их цель не найти текст, а заменить его. Совпадения не будут выведены
* ~~\[Общее] Начиная с данной версии все бета-функции будут встроены в основной релиз, но отделены от стабильного функционала. Активация будет происходить только по согласию пользователя. Данное изменение позволит выпускать больше стабильных релизов и не тратить время на подготовку отдельных бета-версий. Включение путём удаления файла **.nopreview**~~ \
  **Новых номерных версий Shark Remote не планируется!**

### Версия 10 beta 2 / 7.1 beta 2 (9 января)

{% hint style="info" %}
Версия поднялась до 10, чтобы обозначить несколько иной вектор развития Shark Remote.
{% endhint %}

* \[Общее] Исправлены проблемы с запуском.
* \[Общее] Все библиотеки обновлены по последних версий. По умолчанию используется WebView2 актуальной версии (на момент 8 января 2026 года)
* \[Telegram бот] Команда **/abno** переименована в **/netstat**.
* \[Telegram бот] Улучшенная версия команды **/netstat** с названием **/ss**.
* \[WebView2] Мастер настройки полностью заменён на WebUI2 (настройка для отключения WebView2 для дальнейшей настройки Shark Remote останется, т.к. первую настройку можно сделать в браузере и позже подложить папку программе).
* \[WebView2] Отключены лишние функции WebView2, что должно заметно улучшить производительность на слабом железе и немного ускорить процесс скачивания и применения настроек. Плавная прокрутка отключается только при включенном Режиме производительности.
* \[WebView2] Исправлена проблема с применением новых конфигураций из-под WebView2.
* \[Общее] Мелкие улучшения.
* \[Приложение] Убран импорт настроек с Рабочего стола при первом запуске.
* \[Telegram бот] Добавлена базовая реализация истории команд (скрыта для показа)
