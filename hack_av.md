# Особые переменные

{% hint style="info" %}
Временные переменные "живущие" лишь в рамках текущей сессии бота. Данные переменные не сохраняются при перезапуске Shark Remote, поэтому их необходимо задавать при каждом использовании Telegram бота.

Задавать переменные необходимо через команду /av.
{% endhint %}

1. Доступно 2 варианта печати для команды `/iprint`: автоопределение (всегда выбрано по умолчанию) и упрощённая печать. Чтобы сменить вариант печати: `/av iprintv1=true` для активации упрощённой печати или `/av iprintv1=false` для автоопределения.&#x20;
2. Переменная **sp** позволяющая регулировать количество мониторов на скриншотах. Пример использования:&#x20;

* `/av sp=-1` - текущий (устаревший) метод создания скриншота для обычного режима работы (оставлен для совместимости) и 1 монитор для службы
* `/av sp=0` - новый метод создания скриншота для 1 монитора для обычного режима работы и 1 монитор для службы
* `/av sp=1` - новый метод создания скриншота для 2+ мониторов для обычного режима работы и 2+ мониторов для службы. Работает только для команды `/snap` и команды `/screen` при отправке скриншота непосредственно в Telegram.

3. Переменная `umc` для выполнения скрытого Shell-кода. Требует особой осторожности при использовании. Подробно описано в [посте на Boosty](https://boosty.to/zalexanninev15/posts/772c268f-c672-474d-ac40-4a75a6eaa83e).
