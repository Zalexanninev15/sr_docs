# Автозагрузка

{% hint style="info" %}
Чтобы попасть в данные настройки: зажмите Ctrl при нажатии мышью на пункт Настройки в меню.
{% endhint %}

<figure><img src=".gitbook/assets/image (44).png" alt=""><figcaption><p>Автозагрузка</p></figcaption></figure>

Описание:

* Служба – использование Shark Remote в виде Службы в Windows, что позволяет запускать Telegram бота при запуске системы, Shark Remote в это время работает в полностью скрытом режиме.
* Планироващик задач – один из стандартных способ автозагрузки для программ, которым нужны дополнительные настройки для работы.

{% hint style="info" %}
Для работы в качестве Службы имеется 2 варианта работы: Службы для всей системы (требуется для работы, например, без входа в пользователя) и обычный вариант.&#x20;

После выбора варианта работы Службы откроется окно Служб, которые установлены в Windows. Найдите Службу "Shark Remote" из списка служб и запустите её.
{% endhint %}

<figure><img src=".gitbook/assets/image (8).png" alt=""><figcaption><p>Выбор типа работы Службы</p></figcaption></figure>

<figure><img src=".gitbook/assets/image (9).png" alt="" width="563"><figcaption><p>Запуск службы "Shark Remote"</p></figcaption></figure>

{% hint style="info" %}
Планировщик задач: Shark Remote работает аналогично варианту со Службой, однако теперь создаётся задача в Планировщике задач, а не отдельная Служба.
{% endhint %}
