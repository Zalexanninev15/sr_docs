# Файл Меню Избранного

{% hint style="success" %}
Файл: favorites.txt
{% endhint %}

**Меню Избранного** доступно в Telegram боте. Можно использовать команды Telegram бота Shark Remote, встраивать в кнопки Web-приложения, а также создавать обычные ссылки.

<figure><img src="../.gitbook/assets/image (5).png" alt=""><figcaption><p>Пример стандартного меню</p></figcaption></figure>

Всевозможные типы кнопок отображены  ниже в виде готовых примеров, которые можно сразу скопировать и вставить в файл **favorites.txt**, с описанием каждого элемента.

#### Кнопка с командой (только для Telegram Desktop)

`Эхо=>function:@/shell cmd /c echo Hi!`

Описание:

* `Эхо` - текст кнопки
* `=>function:` - означает, что это кнопка Меню Избранного
* `@` - обозначает, что данная кнопка является командой (вставка команды после нажатия кнопки)
* `/shell cmd /c echo Hi!` - выполняемая команда

#### Кнопка с ссылкой

`Просто ссылка=>function:?https://codeberg.com/Zalexanninev15`

Описание:

* `Просто ссылка` - текст кнопки
* `=>function:` - означает, что это кнопка Меню Избранного
* `?` - обозначает, что данная кнопка является ссылкой
* `https://codeberg.com/Zalexanninev15` - открываемая ссылка.\
  Также допускается username Telegram бота (без **@**). Пример:\
  `N.E.T.C.A.L.C.=>function:?STEPLOGIC_NetCalc_bot` (а вот [сам Telegram бот](https://t.me/STEPLOGIC_NetCalc_bot))

#### Кнопка с Web-приложением

`WebApp=>function:!https://browserleaks.com/ip`

Описание:

* `WebApp` - текст кнопки
* `=>function:` - означает, что это кнопка Меню Избранного
* `!` - обозначает, что данная кнопка открывает Web-приложение в Telegram
* `https://myip.ru` - открываемая ссылка Web-приложения (обязательно HTTPS), ссылка может вести на любой сайт. Открываемый сайт может и не быть Web-приложением в Интернете. \
  Также допускается username Telegram бота (без **@**) с Мини-приложением. Пример:\
  `Test Attach=>function:!asmico_attach_bot` (а вот [сам Telegram бот](https://t.me/asmico_attach_bot))

#### Кнопка для копирования

`CopyButton=>function:cТекст`

Описание:

* `CopyButton`- текст кнопки
* `=>function:` - означает, что это кнопка Меню Избранного
* `c` - обозначает, что данная кнопка является кнопкой для копирования текста / ссылки
* `Текст` - Текст или ссылка для копирования

{% hint style="info" %}
Начиная с Shark Remote версии 10 появилась возможность использования [цветных кнопок](https://habr.com/ru/articles/994622/).\
Для их использования необходимо задать, сразу после обозначения, вид кнопки в Telegram как первой буквы после обозначения типа кнопки.<br>

* 🔴 `danger` — красная кнопка
* 🟢 `success` — зелёная кнопка
* 🔵 `primary` — синяя кнопка
* ⚪️ стандартная — привычный прозрачно-серый цвет или иной, в зависимостзависимости от клиента Telegram или выбранной темы оформления<br>

Примеры:

`CopyButton=>function:csТекст`  - 🟢

`Просто ссылка=>function:?phttps://codeberg.com/Zalexanninev15` - 🔵

`WebApp=>function:!dhttps://browserleaks.com/ip` - 🔴

`Эхо=>function:@/shell cmd /c echo Hi!` - ⚪️<br>
{% endhint %}
