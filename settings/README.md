# Настройка Shark Remote

{% hint style="info" %}
Настройка последней версии Shark Remote после первоначальной настройки (Мастер настройки) или вместо (доступно только через WebUI)
{% endhint %}

## Вариант 1: Через WebUI (рекомендуется) → доступен [здесь](https://sharkremote.neocities.org/webui2)

## Вариант 2: Редактирование файлов настроек вручную через текстовый редактор (например: Notepad++)

#### Настройки Shark Remote состоят из 5 основных файлов

* [Файл конфигурации Shark Remote – **main.toml**](main.toml.md)
* [Файл с Пользовательскими переменными – **variables.txt**](variables.txt.md)
* [Файл с Меню – **menu.txt**](menu.txt.md)
* [Файл с Меню Избранного - **favorites.txt**](favorites.txt.md)
* Файл с расположением файла AutoIt3.exe (полный путь к AutoIt3.exe) – **autoit3\_exe.txt**
* [Опциональный файл с флагами (flags) - **flags.txt**](flags.md)

{% hint style="info" %}
Чтобы перейти к данным файлам легче всего сделать клик мышью с зажатым Alt на пункте меню Настройки.
{% endhint %}

{% hint style="warning" %}
К редактированию настроек вручную необходимо подходить с максимальной осторожностью, т.к. даже малейшая неточность может привести к сбоям в Shark Remote, а в некоторых отдельных случаях, сбои будут по всей системе.
{% endhint %}
