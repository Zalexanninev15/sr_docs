# Файл с флагами

{% hint style="success" %}
Файл: flags.txt
{% endhint %}

{% hint style="info" %}
Флаги начинают свою работу после перезапуска Shark Remote.
{% endhint %}

## Доступные флаги

* `big-bang=1` - Убирает ограничение на размер установочных файлов плагинов (не более 10 Мб), позволяя устанавливать плагины любого размера. (версии ниже Shark Remote 7)
* `ninja-mode=1` - Скроет весь интерфейс, Shark Remote будет функционировать в скрытом режиме. (версии ниже Shark Remote 7)
* `kickass-mode=1` - Игнорирует проверки доступности критически важных Интернет-сервисов и продолжает работу (может вызывать проблемы в работе Shark Remote, если проблемы имеются) (версии ниже Shark Remote 7)
* `anti-edge=1` - Использовать конфигуратор через веб-интерфейс, не используя WebView2 (версии ниже Shark Remote 7) (версии ниже Shark Remote 7)
* `not-my-window=1` - Автоматически подстраивает размер окна, если возникают проблемы с отображением. (версии ниже Shark Remote 7)
* `hdpipm2=1` - Принудительно задействует _PerMonitorV2_ на экранах с высоким разрешение (может помочь в решении проблем с отображением в разрешении 1920x1080 и выше). (версии ниже Shark Remote 7)
* `no-crying=1` - Отключает отправку сообщений об ошибках разработчику.

{% hint style="info" %}
Вместо `1` можно использовать `true`, если вам так удобнее.
{% endhint %}
