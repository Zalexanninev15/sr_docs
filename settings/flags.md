# Файл с флагами

{% hint style="success" %}
Файл: flags.txt
{% endhint %}

{% hint style="info" %}
Флаги начинают свою работу после перезапуска Shark Remote.
{% endhint %}

## Доступные флаги

* `knock-knock=1` - Включает операции с shell-кодом.
* `no-crying=1` - Отключает отправку сообщений об ошибках разработчику в GlitchTip (Sentry).

{% hint style="info" %}
Вместо `1` можно использовать `true`, если вам так удобнее.
{% endhint %}
