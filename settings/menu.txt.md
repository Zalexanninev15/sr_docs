# Файл Меню

{% hint style="success" %}
Файл: **menu.txt**
{% endhint %}

**Меню** доступно в Telegram боте. Можно использовать команды Telegram бота Shark Remote.

<figure><img src="https://github.com/Zalexanninev15/NoADS_RU/assets/51060911/06bfb4ec-4d72-4767-b14f-68f9650549e8" alt=""><figcaption><p>Местоположение Меню</p></figcaption></figure>

Пример записи в файле: `start=Показать клавиатуру`

Теперь обновите Меню командой `/menu`

Готово! Меню будет отображаться в боте следующим образом (скриншот ниже), а при нажатии будет срабатывать команда `/start`
