# Разработка плагинов

Плагины можно создавать с использованием следующих скриптовых языков:

* [Python](python.md)
* [PowerShell](powershell.md)
* [AutoIt](autoit3.md)

{% hint style="info" %}
Для создание плагинов рекомендуется использовать редактор кода Visual Studio Code.

Новичкам можно просто следовать инструкции по созданию плагина.
{% endhint %}
